## 5. Key Decisions & Rationale

Do not re-open the decisions in `docs/artifacts/grokdesktop-electron-shell.md`.

| Decision | Rationale |
| --- | --- |
| One window, one `persist:grokdesktop` session, our own tab strip | The site stays the UI. Tabs share one login. |
| Native titlebar, strip underneath | Drag, snap, and maximize stay with the desktop. |
| Ctrl+W on the last tab does nothing | Closing the window is the quit path. |
| Non-grok main-frame links go to the system browser; redirects and popups stay | Login is redirects and popups, not a guessed auth-host allowlist. |
| `linux.publish: null` | Stops electron-builder from writing `app-update.yml`. There is no updater. |
| Chrome 157 user agent in one file | grok.com should see a normal browser. Update that constant if the site rejects it. |

## 7. Next Steps

Local runbook. Do these in order on the Fedora machine.

1. Install build tools and the libraries Electron needs. Node must be 22 or newer (`node -v`). If Fedora's `nodejs` package is older, install a current Node before continuing.

   ```bash
   sudo dnf install git nodejs npm gtk3 libnotify nss libXScrnSaver libXtst xdg-utils at-spi2-core libuuid rpm-build
   ```

2. Get this branch. After the pull request merges, `main` is enough and you can skip the checkout.

   ```bash
   git clone https://github.com/IsaacSimms/GrokDesktop.git
   cd GrokDesktop
   git checkout cursor/electron-shell-4202
   npm install
   npm test
   ```

   `npm test` must pass before you start the app. It does not open a window and it does not call grok.com.

3. Run it from source and sign in.

   ```bash
   npm start
   ```

   One window opens on https://grok.com with the Fedora titlebar and the tab strip under it. Sign in on that page. Quit by closing the window. Run `npm start` again. You should still be signed in, and the same tabs and window size should come back. Start it a second time while it is open. That launch should focus the existing window, not open another.

   Tabs: the **+** button or Ctrl+T opens https://grok.com. Click a tab to switch. Ctrl+W closes the active tab. Ctrl+W on the only tab leaves it. Two tabs should be two independent grok.com pages.

   Click a non-grok link. The tab stays on grok.com and the system browser opens. A download should appear in `~/Downloads` with no extra download window. Attach a file with the normal system file dialog. If you use voice, the page's mic or camera request should succeed. A notification request should not.

4. Build and install the rpm. Do this on Fedora. The copy built in the agent VM was not published.

   ```bash
   npm run dist
   sudo dnf install ./release/grokdesktop-0.1.0.x86_64.rpm
   ```

   The version in the filename follows `package.json` (`0.1.0` today). Launch **GrokDesktop** from the app grid. It uses the same `~/.config/GrokDesktop` directory as `npm start`, so the login carries over.

   On a Wayland session the app selects the native Wayland path when `WAYLAND_DISPLAY` is set. Do not set `ELECTRON_OZONE_PLATFORM_HINT=x11` or pass `--ozone-platform=x11`.

5. Optional: attach the rpm to a GitHub Release yourself. Skip this unless you want a release. The repo does not publish one for you.

   ```bash
   gh release create v0.1.0 release/grokdesktop-0.1.0.x86_64.rpm \
     --title "v0.1.0" \
     --notes "Unofficial Fedora rpm. Not affiliated with xAI."
   ```

   Do not describe it as an official xAI or Grok app.

6. If you need to sign out, quit the app and delete the data directory. Uninstalling the rpm does not delete it.

   ```bash
   rm -rf ~/.config/GrokDesktop
   ```

7. If grok.com refuses the window or the login page looks like an outdated browser, change only `src/session/user-agent.ts` to a current Linux Chrome user agent. Keep the string free of `Electron`. Then `npm start` again, or rebuild the rpm.

## 8. Must-Knows for the New Thread

- The app is unofficial and not affiliated with xAI. Do not ship an xAI or Grok logo.
- One login. No account switcher, no tray, no global hotkey, no desktop notifications, no page injection.
- Closing the window quits. Ctrl+W never quits.
- Auth hosts are handled by redirects and popups, not by adding hosts to an allowlist.
- A later feature is a new module in this repo, rebuilt into a new rpm. No plugin host.
- Our code stays GPLv3. `LICENSE` stays. Electron and Chromium keep their own licenses; the rpm already carries them.
