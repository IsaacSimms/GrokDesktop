# GrokDesktop — Context & Architecture Reference

GrokDesktop is an unofficial Fedora desktop shell for [grok.com](https://grok.com). The website stays the UI. The shell adds one persistent login, tabs drawn in the window title bar, and a window that restores its tabs and bounds. It is a single Electron process with no plugin host, no in-app updater, and no injection into the grok.com page. Install, rpm, and uninstall steps live in [README.md](README.md).

GrokDesktop is not affiliated with xAI. The icon at `build/icon.png` is original artwork from `scripts/make-icon.py`.

The original v1 plan is [docs/artifacts/grokdesktop-electron-shell.md](docs/artifacts/grokdesktop-electron-shell.md). Where that plan says the tab strip sits under a native title bar, the code has moved on: the strip is the title bar. This file describes the code.

### `src/main.ts` — process boot

The entry (`package.json` `"main": "dist/main.js"`) calls `app.setName("GrokDesktop")`, applies Wayland switches, takes the single-instance lock, and on `ready` clears the menu, configures the persistent session, installs permission and download handlers, and opens the window. It contains no feature logic.

### `src/window/` — the shell window

- `open.ts` — creates the one `BrowserWindow`, defers show until the strip is ready, blocks the shell page from navigating off `file:`.
- `constants.ts` — default 1200×800, title-bar overlay colors, `TAB_STRIP_HEIGHT` 40.
- `wayland.ts` — pure switch list. Applied from `main.ts` before `ready`.
- `shortcuts.ts` — pure Ctrl+T / Ctrl+W / Ctrl+Left / Ctrl+Right mapping.
- `assets.ts` — paths from the compiled `dist/window` module to `dist/renderer` and `dist/build/icon.png`.

### `src/tabs/` — pages inside the window

- `model.ts` — immutable tab list. `HOME_URL` is `https://grok.com`.
- `title.ts` — `tabTitle`. Empty means the strip shows the URL. Bare "Grok", a leading or trailing "Grok" separator, and an `http(s)` title all count as empty.
- `host.ts` — one `WebContentsView` per tab on the shared session, IPC, layout, save. `page-title-updated` stores `tabTitle`. A navigation leaves the current label in place until the document title itself changes.

### `src/links/` — where a navigation is allowed to go

- `classify.ts` — pure `classifyLink`. No Electron imports.
- `attach.ts` — `will-navigate`, `will-redirect`, `setWindowOpenHandler`, child windows.

### `src/session/` — the one login

- `partition.ts` — `persist:grokdesktop`.
- `configure.ts` — `session.fromPartition`, Chrome user agent on the session and `app.userAgentFallback`.
- `user-agent.ts` — the Chrome string. It must not contain `Electron`.
- `preferences.ts` — `contextIsolation`, `sandbox`, `nodeIntegration: false`, `webSecurity: true`.
- `download-path.ts` — collision-safe filename. `downloads.ts` points `will-download` at the Downloads folder.

### `src/permissions/` — prompt policy

- `decide.ts` — `media` is allowed. Every other permission string is denied.
- `install.ts` — wires that function to both the permission-check handler and the permission-request handler.

### `src/persist/` — restore

- `state.ts` — JSON shape, grok-only tab filter, bounds floor of 200×200.
- `file.ts` — `{userData}/window-state.json`.

### `src/renderer/` — title-bar page only

- `index.html` — strip markup and a strict CSP. Loaded with `loadFile` into the shell `BrowserWindow`.
- `tab-strip.css` — 40px strip positioned with `titlebar-area-*`. The strip drags the window. Tabs and **+** do not.
- `tab-strip.ts` — DOM render. Talks to `window.grokdesktop`. Compiled on its own and excluded from the CommonJS project.
- `preload.ts` — `contextBridge` API. Imports only `electron`.

### `src/ipc.ts` — channel contract

String constants shared by the main process. The preload repeats the same strings inline. `test/preload.test.ts` fails if they drift or if the preload imports anything except `electron`.

### `scripts/`

- `copy-static.mjs` — copies `index.html` and `tab-strip.css` to `dist/renderer` after `tsc`.
- `copy-notices.mjs` — copies Electron's `LICENSE` and `LICENSES.chromium.html` into `build/third-party/` when those files exist, and writes `README.txt`. `npm run dist` runs this. `npm run build` does not.
- `make-icon.py` — draws `build/icon.png` (512px). Not part of `build` or `dist`.

## Architecture Patterns

The process is one partition, one window, and a list of `WebContentsView`s. Feature code is a pure module plus a thin Electron adapter. There is no dependency-injection container and no `interface` declaration. `LinkHost` and `TabHost` are structural `type`s at the adapter boundary.

### Layering & Seams

| Concern | Pure module | Electron adapter |
|---------|-------------|------------------|
| Tab list | `tabs/model.ts` (`openTab`, `closeTab`, `switchTab`, `setTabUrl`) | `tabs/host.ts` (`attachTabs`) |
| Tab label | `tabs/title.ts` (`tabTitle`) | `tabs/host.ts` `page-title-updated` |
| Link decision | `links/classify.ts` (`classifyLink`) | `links/attach.ts` (`attachLinkHandlers`) |
| Permission | `permissions/decide.ts` | `permissions/install.ts` |
| Saved window | `persist/state.ts` (`parseWindow`, `serializeWindow`) | `persist/file.ts` |
| Download filename | `session/download-path.ts` | `session/downloads.ts` |
| Shortcuts | `window/shortcuts.ts` (`shortcutFor`) | `tabs/host.ts` `before-input-event` |
| Region capture | `capture/decide.ts`, `capture/portal-messages.ts` | `capture/portal.ts` (`installCapture`) |
| Wayland switches | `window/wayland.ts` (`waylandSwitches`) | `main.ts` `app.commandLine.appendSwitch` |
| Asset paths | `window/assets.ts` | `window/open.ts` |
| WebPreferences | `session/preferences.ts` | shell window, each tab view, each child window |
| Tab-strip IPC | `ipc.ts` names. Preload repeats them as string literals. | `tabs/host.ts` handlers, `preload.ts` bridge |

`TabStripState` (`{ tabs: string[]; titles: string[]; activeIndex: number }`) is declared three times: `src/ipc.ts`, `src/renderer/preload.ts`, and `src/renderer/tab-strip.ts`. `titles[i]` is the thread name for `tabs[i]`, or `""` while the page title is still the site default. The preload cannot import `ipc.ts` (sandbox). The tab-strip script is a separate compile with no imports. The preload test is what keeps the channel strings aligned.

Pure functions return the same object when nothing changed. Adapters use that identity check (`next === state`) to skip view and IPC work.

### Process lifetime

- **One process.** `app.requestSingleInstanceLock()` runs at startup. A failed lock calls `app.quit()`. `second-instance` calls `focusMainWindow` (restore if minimized, then show and focus). `window-all-closed` quits. There is no tray and no macOS keep-alive branch.
- **One session.** `configureSession()` returns `session.fromPartition("persist:grokdesktop")`. Tab views and login child windows set `webPreferences.session` to it. The shell `BrowserWindow` does not: it loads the local title-bar file on the default session, so grok.com cookies are not on that page.
- **One main window.** `mainWindow` is a module-level variable in `window/open.ts`. `ipcMain` is process-global. `attachTabs` registers handlers and removes them on `closed`. A second `attachTabs` without a close would stack handlers. The lock is what prevents that.
- **Shortcut lifetime.** `installCapture` registers one GlobalShortcuts session after `attachTabs` and releases that session when the window closes. Closing the window still quits. There is no tray, and the shortcut is gone after quit. A portal failure is one `GrokDesktop capture:` line on the main-process error stream. The window still opens.
- **User data.** `app.setName("GrokDesktop")` runs before `ready`, so Electron's Linux user-data directory is `~/.config/GrokDesktop`. `npm start` and an installed copy share it. Cookies for the partition live under that directory. `window-state.json` is `{userData}/window-state.json`. Deleting the directory signs the user out.

### Boot sequence

1. `app.setName("GrokDesktop")`.
2. `applyWayland` appends Chromium switches when `WAYLAND_DISPLAY` is non-empty. This has to happen before the app is ready.
3. Single-instance lock. Quit immediately when another process holds it.
4. On `ready`: `Menu.setApplicationMenu(null)`, `configureSession`, `installPermissions`, `installDownloads`, `openMainWindow`.
5. `openMainWindow` reads `window-state.json`, creates the `BrowserWindow` with `show: false`, calls `attachTabs`, calls `installCapture`, and loads `dist/renderer/index.html`.
6. `attachTabs` creates one `WebContentsView` per saved URL and loads it.
7. The strip script calls `stripReady` after its first `getTabs` (success or failure). The main process then `layout()`s and `show()`s. A 5 second timer shows the window if that IPC never arrives.

### WebPreferences

`secureWebPreferences` always sets:

- `contextIsolation: true`
- `nodeIntegration: false`
- `sandbox: true`
- `webSecurity: true`

The preload path is passed only for the shell window. Tab views and child windows get the same flags with no preload, so `window.grokdesktop` exists only on the title-bar page.

The shell page CSP in `index.html` is `default-src 'none'; style-src 'self'; script-src 'self'`.

The shell `webContents` cancels `will-navigate` unless the URL starts with `file:`, so the title-bar page cannot be navigated away. `page-title-updated` is cancelled and the window title stays `GrokDesktop`. The application menu is removed and the menu bar is hidden.

### Wayland

`waylandSwitches` returns nothing when `WAYLAND_DISPLAY` is missing or empty. When it is set, the switches are:

| Switch | Value | Why |
|--------|-------|-----|
| `ozone-platform` | `wayland` | Native Wayland. The list never contains `x11`. |
| `enable-features` | `WaylandWindowDecorations` | Server-side window decorations. |
| `disable-features` | `NativeViewHostManagesLayers` | Electron 45 hides the Wayland window-control overlay unless this Chromium feature is off. Hidden overlay means no minimize, maximize, or close. |

Do not set `ELECTRON_OZONE_PLATFORM_HINT=x11` or pass `--ozone-platform=x11`.

### Permissions

`decidePermission` returns true only for `"media"` (microphone and camera). `notifications`, `display-capture`, `geolocation`, `clipboard-read`, and any other string return false. Both `setPermissionCheckHandler` and `setPermissionRequestHandler` call it. There is no permission window. Region capture does not grant the page `display-capture`. The main process calls the Screenshot and GlobalShortcuts portals itself.

`<input type="file">` is not intercepted. Chromium shows the system file dialog.

### Downloads

`will-download` calls `item.setSavePath` under `app.getPath("downloads")`. The filename is `path.basename`, control characters stripped. Empty, `.`, and `..` become `download`. Collisions use `name (1).ext` through `name (999).ext`, then `name-{timestamp}.ext`. The `exists` check is injected so the pure function can be tested. There is no download UI.

### Packaging

`npm run dist` builds, runs `copy-notices.mjs`, then `electron-builder --linux rpm --x64`. The rpm filename follows `package.json` version (`grokdesktop-0.1.0.x86_64.rpm` at version 0.1.0). electron-builder's packager needs `libcrypt.so.1` (`libxcrypt-compat` on Fedora) and `rpm-build`. There is no publish config (`linux.publish` is null) and no CI workflow.

`files` packs `dist/**/*` except source maps, plus `build/icon.png`, `package.json`, `LICENSE`, and the production `dbus-next` tree. The custom `files` list replaces electron-builder's default, so `node_modules` is not packed unless named there. `extraResources` packs `build/third-party` and `LICENSE`.

`shellAssetPath(__dirname, "icon.png")`, with `__dirname` of `dist/window/open.js`, resolves to `dist/build/icon.png`. The builder `files` entry places `build/icon.png` at the app root, which is the path `linux.icon` uses for the desktop entry. Those two locations differ.

Desktop entry fields from `package.json` `build.linux`: Name `GrokDesktop`, Categories `Network;`, `StartupWMClass` `grokdesktop`, executable `grokdesktop`.

## IPC

There is no HTTP API. The title-bar page talks to the main process through these channels. Names are the values in `IpcChannel`.

| Channel | Direction | Payload | Effect |
|---------|-----------|---------|--------|
| `tabs-get` | renderer `invoke` → `ipcMain.handle` | none | Returns `{ tabs, titles, activeIndex }`. |
| `tabs-updated` | main `send` → `ipcRenderer.on` | `TabStripState` | Re-renders the strip. Sent on open, close, switch, when a grok.com navigation changes a tab URL, and when a page title changes. A title-only update does not rewrite `window-state.json`. |
| `tabs-open` | renderer `send` | none | Opens `https://grok.com` and activates it. |
| `tabs-close` | renderer `send` | integer index | Closes that tab. Non-integers are ignored. |
| `tabs-switch` | renderer `send` | integer index | Activates that tab. |
| `strip-ready` | renderer `send` | none | Main process shows the window. |

`close` and `switch` indexes are checked with `typeof index === "number" && Number.isInteger(index)` before they reach the model.

## Key Models

| Model | Key fields |
|-------|-----------|
| `TabState` | `tabs: readonly string[]`, `activeIndex: number`. `createTabState()` is one `HOME_URL` at index 0. |
| `TabStripState` | `tabs: string[]`, `titles: string[]`, `activeIndex: number`. The IPC payload. Shallow copies. `titles` are not saved. `tabTitle` in `tabs/title.ts` turns a document title into `titles[i]`. |
| `PersistedWindow` | `bounds: WindowBounds \| null`, `tabs: string[]`, `activeIndex: number`. |
| `WindowBounds` | `x`, `y`, `width`, `height`. All finite. Width and height at least 200. |
| `LinkDecision` | `"stay"` \| `"external"` \| `"new-tab"` \| `"child-window"`. |
| `LinkKind` | `"main-frame"` \| `"redirect"` \| `"window-open"`. |
| `Shortcut` | `"open-tab"` \| `"close-tab"`. |
| `TabHost` | `{ layout, saveNow, pasteClipboard }` returned by `attachTabs`. `open.ts` calls `layout` just before the first show. `pasteClipboard` restores, shows, and focuses the window, focuses the active view, and calls `webContents.paste()`. |
| `LinkHost` | `{ openTab, parent, session }` passed into `attachLinkHandlers`. |

`window-state.json`:

```json
{
  "bounds": { "x": 0, "y": 0, "width": 1200, "height": 800 },
  "tabs": ["https://grok.com"],
  "activeIndex": 0
}
```

`parseWindow` rules:

- Missing, empty, or invalid JSON becomes `{ bounds: null, tabs: ["https://grok.com"], activeIndex: 0 }`.
- A bounds object that fails the finite / 200px check becomes `bounds: null`. The window then uses 1200×800 and lets the window manager choose the position (no `x` / `y` in the `BrowserWindow` options).
- Tab strings that fail `isGrokUrl` are dropped. If none remain, the fallback is one `https://grok.com` tab.
- `activeIndex` maps onto the surviving list: the same original index if it survived, otherwise the next surviving index after the requested one, otherwise the last tab.

`readWindowState` treats any filesystem error as a missing file. `writeWindowState` creates the directory and writes synchronously. It does not catch write errors.

## Window and Title-Bar Tabs

The shell window is a real frame (`frame: true`) with `titleBarStyle: "hidden"` and `titleBarOverlay`. The overlay height is 40, color `#181818`, symbol color `#cccccc`, matching `tab-strip.css` and the window `backgroundColor`. Native minimize, maximize, and close stay in the overlay. The strip fills `titlebar-area-*` beside those buttons. `#strip` is `-webkit-app-region: drag`. `.tab` and `#new-tab` are `no-drag`.

`TAB_STRIP_HEIGHT` in `src/window/constants.ts` and the `40px` height in `src/renderer/tab-strip.css` are the same number. Page views are laid out at `y: 40` with height `contentHeight - 40`. Only the active view is visible and given bounds.

Each tab is a `WebContentsView` (Electron 45), child of `win.contentView`, with the persistent session and `CHROME_USER_AGENT`. The shell does not inject CSS or JavaScript into grok.com and does not read the page DOM. Tab labels are the URL hostname plus pathname (`/` omitted), or `"Grok"` when the URL cannot be parsed.

Shortcuts are `before-input-event` on the shell `webContents` and on every tab view. They run only while that webContents is receiving input. Ctrl+T opens a tab. Ctrl+W closes the active tab. Ctrl+Left and Ctrl+Right activate the previous and next tab. `switchTab` ignores an out-of-range index, so the ends stop. The mapping requires `keyDown`, Control, and no Alt, Meta, or Shift. The key is lowercased, so the arrows match `arrowleft` and `arrowright`. A matched shortcut calls `preventDefault`. Ctrl+Alt+S is not in that mapping.

Ctrl+Alt+S is the GlobalShortcuts portal binding `capture-region`, suggested as `<Control><Alt>s`. The description GNOME shows is `Capture a region and paste it into GrokDesktop`. Before any other portal call, the main process registers the app id `grokdesktop` on `org.freedesktop.host.portal.Registry` so it matches `grokdesktop.desktop`. The session is created when the window opens and dropped when the window closes. A press calls Screenshot with `interactive: true`, `modal: false`, and an empty `parent_window`. Electron 45 has no `clipboard.writeImage`. A finished PNG is checked with `nativeImage.createFromBuffer`, then written with `clipboard.write` and a `ClipboardItem` of type `image/png`. `pasteClipboard` then raises the window and pastes into the active tab. The shell does not press Enter and does not inject into grok.com. Cancelling the region tool leaves the window and the clipboard alone. A second press while a region tool is open is ignored.

Tab model behavior the host relies on:

- `openTab` appends and activates the new index. Default URL is `https://grok.com`.
- `closeTab` on the only tab, or on a bad index, returns the same state. The host then does nothing. Closing the window is the quit path.
- Closing the active tab selects `min(index, last)`. Closing a tab left of the active one decrements the index.
- `switchTab` to the current index or an out-of-range index returns the same state.
- `did-navigate` and `did-navigate-in-page` call `setTabUrl` only when `isGrokUrl` is true. A sign-in navigation does not overwrite the saved grok.com URL.

Saves:

- Every `publish()` (open, close, switch, grok.com URL change) writes `window-state.json` immediately.
- `resize` lays out views and writes bounds after 200ms. `move` uses the same debounce.
- `close` clears the debounce and writes immediately.

The strip script subscribes to `tabs-updated` first, then `getTabs()`. If an update arrived during the invoke, the invoke result is discarded. It always sends `strip-ready` afterward, including when `getTabs` rejects.

## Link Classification

`attachLinkHandlers(contents, host, mode)` is installed on every tab (`mode: "tab"`) and, from `did-create-window`, on every child window (`mode: "popup"`).

`classifyLink` decides in this order:

1. `kind: "redirect"` → `stay`, for any URL. Login redirect chains stay in the current tab. The `external` branch in the `will-redirect` listener is unreachable for this classifier.
2. `kind: "window-open"`:
   - `popup` or a sign-in URL → `child-window`
   - otherwise a grok URL → `new-tab`
   - otherwise → `external`
3. `kind: "main-frame"`: grok URL or sign-in URL → `stay`. Anything else → `external`.

`isGrokUrl` accepts `https` whose hostname is `grok.com` or ends with `.grok.com`, after stripping one trailing dot. `http`, lookalikes (`grok.com.evil.com`), and unparseable strings fail.

Sign-in hosts (exact hostname, `https` only): `accounts.google.com`, `appleid.apple.com`, `accounts.x.ai`.

Cookie-handoff paths (exact pathname, `https` only):

| Host | Paths |
|------|-------|
| `accounts.youtube.com` | `/accounts/SetSID`, `/accounts/CheckConnection` |
| `auth.grok.com` | `/set-cookie`, `/delete-cookie` |
| `auth.grokusercontent.com` | `/set-cookie`, `/delete-cookie` |
| `auth.x.ai` | `/set-cookie`, `/delete-cookie` |

`auth.grok.com` is also a grok host. A `window.open` to any other path on that host is `new-tab`. A `window.open` to another path on `auth.grokusercontent.com`, `accounts.youtube.com`, or `auth.x.ai` is `external` unless it is a popup.

`isPopupWindowOpen` is true when the disposition is `new-window` or `other`, or when `features` matches `(^|,) popup|width|height` as a feature token. `foreground-tab` with empty features or only `noopener` is not a popup.

Adapter actions:

| Decision | What `attach.ts` does |
|----------|------------------------|
| `stay` | Lets the navigation proceed. |
| `external` | `preventDefault` on `will-navigate` (tabs only). `shell.openExternal` for `http:` and `https:` only. `javascript:` and `file:` are dropped. Open failures are ignored. |
| `new-tab` | `host.openTab(url)` and `setWindowOpenHandler` returns `deny`. |
| `child-window` | `setWindowOpenHandler` returns `allow` with `parent` set to the main window, the same session, `secureWebPreferences()` with no preload, menu bar hidden, title `GrokDesktop`, and the Chrome user agent applied in `did-create-window`. |

Popup mode skips `will-navigate` classification so a login window can move between hosts. Child windows get the same window-open handler. The shell does not turn a non-grok popup into a tab. When the site closes a child window, it stays closed.

## Session Identity

`CHROME_USER_AGENT` in `src/session/user-agent.ts`:

```
Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/157.0.8103.38 Safari/537.36
```

It is applied in four places: `ses.setUserAgent`, `app.userAgentFallback`, each tab `webContents.setUserAgent`, and each child window `webContents.setUserAgent`. Change the constant when grok.com treats the window as an outdated browser. Keep the string free of `Electron`. `test/session.test.ts` locks the Chrome token, the Linux platform token, and the absence of `Electron`.

## Frontend Conventions

The renderer is one static page. No React, no bundler, no CSS framework.

### Page

`index.html` loads `tab-strip.css` and `tab-strip.js` as same-origin relative URLs. `tab-strip.ts` declares `grokdesktop` as a global `TabBridge`. It builds tab DOM with `createElement` and `replaceChildren` on each state. The visible label is `titles[i]` when that string is non-empty, otherwise the hostname and path. The button tooltip stays the full URL. Buttons are `type="button"`. The close control sets `aria-label` to `Close {label}`. The new-tab button's label is `New tab`.

### Layout

```
BrowserWindow (title bar overlay, 40px)
├── shell webContents — index.html in the title-bar area
│   └── #strip
│       ├── #tabs
│       │   └── .tab
│       │       ├── button.select — switchTab
│       │       └── button.close — closeTab
│       └── #new-tab — openTab
└── WebContentsView per tab — grok.com, y = 40, only the active one visible
```

Tab width is `flex: 0 1 180px`, minimum 120px, maximum 220px. `#tabs` scrolls horizontally.

Colors are CSS variables on `:root` (`--strip` `#181818`, `--editor` `#1f1f1f`, `--accent` `#0078d4`). The overlay `color` and `symbolColor` are the matching hex values in `TITLE_BAR_OVERLAY`, not the CSS variables. Change both when the chrome color changes.

## Code Style

- Double quotes, semicolons, two-space indent.
- Exported functions have explicit return types.
- Electron value imports come from `"electron"`. Type-only Electron imports use `import type`.
- State updates are immutable. Returning the input object means "no change."
- Adapters guard `isDestroyed()` before touching a window or `webContents`.
- Comments are for constraints the next edit can break: the preload sandbox import rule in `preload.ts`, the `NativeViewHostManagesLayers` reason in `wayland.ts`, and the CSS height coupling on `TAB_STRIP_HEIGHT`.
- The preload's channel strings are duplicated on purpose. Do not add a local import to `src/renderer/preload.ts`. A local `require` crashes in the sandbox, `grokdesktop` never appears, and **+** does nothing.
- `src/renderer/tab-strip.ts` stays free of imports so the separate ES2022 emit remains a classic script tag.

## Testing Conventions

### Vitest

- **Location:** `test/*.test.ts`. Included only by `vitest.config.mjs`. Not compiled by either `tsc` project.
- **Command:** `npm test` → `vitest run`. Node environment. No Electron, no display, no request to grok.com.
- **Method naming:** `describe` is the concern (`"link classifier"`, `"tab model"`). `it` is a behavior sentence (`"closes the active tab and selects the neighbor"`).
- **Mocking:** no mock library. Pure functions take their inputs directly. `downloadFilePath` takes an `exists` callback. `applyWayland` takes an `appendSwitch` callback. `persist-file.test.ts` uses `fs.mkdtempSync` under `os.tmpdir()`. `preload.test.ts` reads `src/renderer/preload.ts` as text.
- **Assertions:** `expect(...).toBe`, `toEqual`, `toContain`, `not.toContain`.
- **Latest run:** 12 files, 60 tests, passing (`vitest run` on 2026-11-06).

`npm run build` (`tsc -p tsconfig.json && tsc -p tsconfig.renderer.json && node scripts/copy-static.mjs`) completes and writes `dist/main.js`, `dist/renderer/preload.js`, `dist/renderer/tab-strip.js`, `dist/renderer/index.html`, and `dist/renderer/tab-strip.css`.

## Dev Commands

```bash
# Install dependencies. Electron's postinstall downloads the runtime.
npm install

# Unit tests. Does not launch Electron.
npm test

# Compile main (CommonJS) and the tab strip (separate project), then copy html and css.
npm run build

# Build and open one window on https://grok.com.
npm start

# Build, copy third-party notices, write release/grokdesktop-<version>.x86_64.rpm.
# Needs libcrypt.so.1 (sudo dnf install libxcrypt-compat rpm-build).
npm run dist

# Unpacked tree for a per-user install. See README.md.
npx electron-builder --linux dir --x64

# Regenerate build/icon.png. Not part of npm run build.
python3 scripts/make-icon.py
```

User-local install paths, the rpm install, and uninstall are in [README.md](README.md). A second launch focuses the existing window. Closing the window quits.
